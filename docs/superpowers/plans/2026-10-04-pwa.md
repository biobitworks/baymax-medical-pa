# Baymax PWA Implementation Plan

Goal: Make the existing Baymax web interface installable with a safe offline fallback.
Architecture: vite-plugin-pwa injects an asset manifest into a custom Workbox worker. A small React component owns install and update controls independently of care state.
Tech stack: React, TypeScript, Vite, Workbox, Playwright.

- [x] Write browser acceptance tests for production manifest/icons, worker control, offline navigation, API exclusion, installation and update consent; run against the original build to observe missing behavior.
- [x] Add vite-plugin-pwa injectManifest configuration, src/sw.js, public/offline.html and reproducible PNG icons. Only static assets are precached; navigation is network-only with an offline fallback.
- [x] Add src/pwa/PwaControls.tsx and its styles; mount alongside App. Register on production only, listen for beforeinstallprompt/appinstalled, show iOS guidance, and ask before activating updates.
- [x] Add app metadata, standalone safe-area styles, hosting cache headers and README installation instructions.
- [x] Build and run the browser suite, inspect the mobile layout, review the diff, and commit the isolated branch.
