# Golden Path to Golden Years

Baymax's product objective is not "maximize a longevity score."

The target is a governed personal-healthspan loop:

```text
observe
→ establish provenance
→ classify privacy/compliance
→ compare to personal baseline
→ combine with explicit personal values
→ produce a bounded recommendation
→ expose uncertainty
→ obtain authorization
→ observe the result
→ update successor state
→ evaluate learning/retention
```

## Value hierarchy

1. safety and hard constraints
2. medical authority boundary
3. evidence sufficiency
4. user autonomy and privacy
5. explicit personal values
6. healthspan goals
7. commitments and current context
8. preferences
9. convenience/cost

No model may silently rewrite this hierarchy.

## MVP scenario

Synthetic or explicitly authorized observations:
- sleep below personal baseline
- resting heart rate or recovery signal different from baseline
- scheduled important commitment
- planned workout/activity
- personal values: healthspan + honoring commitments

Baymax may recommend a lower-risk wellness adjustment while explicitly stating what is observed, inferred, and unknown.

## Living model

Three distinct adaptation layers:

1. **Context adaptation** — FCG changes; weights do not.
2. **Preference/value adaptation** — user-confirmed successor value state.
3. **DAISy model adaptation** — governed checkpoint update with acquisition and retention evaluation.

A "learns without forgetting" claim requires measured sequential retention evidence. MMR/FCG custody alone does not prevent catastrophic forgetting.
